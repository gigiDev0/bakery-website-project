
# Bakery Website Project

A responsive bakery website developed as part of a group academic project. The website showcases products, layout design, and basic front-end development skills.

---

##  Project Overview
This project was built to demonstrate fundamental web development concepts including page structure, styling, and user interface design.

---

##  Features
- Homepage design
- Product display section
- Basic responsive layout
- Clean and simple user interface

- CSS
